# Notebooks de exploración

Se conservan los notebooks originales de ETL y puentes batch/streaming.
Abrir Jupyter desde la raíz del repositorio para mantener las rutas de datos.

El código ejecutable y los comandos vigentes están en [pipelines/local](../pipelines/local/)
y en la [guía de ejecución local](../docs/ejecucion_local.md).
Los notebooks son ejercicios interactivos y no se sincronizan automáticamente con los scripts.
